Block Merge Rush — Data & Account Deletion

Local game data

Local saves can be deleted inside the game from Settings → Account & Privacy → Delete Data / Account.

Online account data

If a future Android release enables a Block Merge Rush online account, this public page must provide a working way to request deletion of the account and associated server data.

Developer action required before enabling online accounts: connect this page to the production deletion endpoint or verified support workflow, and replace this notice with the real process.

Retention

Any data that must be retained for security, fraud prevention, legal or billing obligations must be disclosed in the production Privacy Policy.
